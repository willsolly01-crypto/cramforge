1
Install dependencies
npm install · ~30 seconds
▼

Open your terminal (Command Prompt or Terminal) and run these two commands:

cd Downloads/cramforge-v2/cramforge
npm install
ℹ️ This downloads React, pdfkit, Stripe, Supabase, and Vite. It'll take about 30 seconds and create a node_modules/ folder.

✅ Test it worked: run npm run dev — the app should open at http://localhost:5173 (it'll show a login screen).

2
Create your .env file
API keys and secrets
▼

In your cramforge folder, create a new file called exactly .env (no extension). Paste this in:

VITE_SUPABASE_URL=https://YOUR-PROJECT-ID.supabase.co
VITE_SUPABASE_ANON_KEY=eyJ...your-anon-key...
ANTHROPIC_API_KEY=sk-ant-...your-key...
SUPABASE_URL=https://YOUR-PROJECT-ID.supabase.co
SUPABASE_ANON_KEY=eyJ...your-anon-key...
SUPABASE_SERVICE_ROLE_KEY=eyJ...service-role-key...
STRIPE_SECRET_KEY=sk_test_...your-test-key...
STRIPE_PRICE_ID=price_...fill-in-step-4...
STRIPE_WEBHOOK_SECRET=whsec_...fill-in-step-4...

Where to find each value:

VariableWhere to find it
VITE_SUPABASE_URL
SUPABASE_URL		 Supabase dashboard → your project → Project Settings → API → Project URL
VITE_SUPABASE_ANON_KEY
SUPABASE_ANON_KEY		 Supabase → Project Settings → API → anon public key
SUPABASE_SERVICE_ROLE_KEY Supabase → Project Settings → API → service_role secret key (keep this secret!)
ANTHROPIC_API_KEY console.anthropic.com → API Keys → Create new key
STRIPE_SECRET_KEY dashboard.stripe.com → Developers → API Keys → Secret key
STRIPE_PRICE_ID Fill in after Step 4 (creating your Stripe product)
STRIPE_WEBHOOK_SECRET Fill in after Step 4 (setting up webhook)
⚠️ Never commit your .env file to git. There's already a .gitignore in the project that excludes it — don't remove it.
3
Run database migrations
Supabase SQL Editor · 9 files in order
▼

Go to supabase.com/dashboard → your project → SQL Editor → click New query.

For each file below: open the file in your cramforge folder, copy all the contents, paste into the SQL editor, click Run. Wait for the green tick, then do the next one.

💡 The files are in your cramforge-v2/cramforge/ folder. They end in .sql. Run them in the exact order listed.
#FileWhat it creates
1supabase-setup.sqlCore tables: profiles, usage
2supabase-monthly-usage-migration.sqlMonthly usage caps for Pro plan
3supabase-referral-migration.sqlReferral codes and bonuses
4supabase-user-data-migration.sqlCross-device state sync
5supabase-shared-sets-migration.sqlPublic question sets
6supabase-social-migration.sqlUsernames, study sessions, leaderboard
7supabase-classes-migration.sqlTutor classes with join codes
8supabase-bank-migration.sqlQuestion bank features
9supabase-quick-study-migration.sqlXP columns + Quick Study RPC
ℹ️ If you see a "column already exists" warning, that's fine — keep going. Each migration is safe to re-run.

✅ Check it worked: Supabase → Table Editor — you should see tables including profiles, usage, study_sessions, classes.

4
Set up Stripe
Create product · Get price ID · Webhook
▼
✓
Create a product in Stripe
Stripe dashboard → Products → Add product. Name: "CramForge Pro". Price: $8.99/month, recurring, monthly. Save it.
✓
Copy the Price ID into your .env
After saving the product, you'll see a Price ID that starts with price_1... — copy it into your .env as STRIPE_PRICE_ID.
✓
Skip the webhook for now (do it after deploy)
The webhook needs your live Vercel URL, which you won't have until Step 5. Come back here after deploy.
5
Push to GitHub
git init · commit · push
▼

Go to github.com/new and create a new private repository called cramforge. Don't add a README. Then in your terminal:

cd Downloads/cramforge-v2/cramforge
git init
git add -A
git commit -m "initial commit"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/cramforge.git
git push -u origin main

Replace YOUR-USERNAME with your actual GitHub username. GitHub will ask you to log in the first time.

6
Deploy to Vercel
Import repo · Add env vars · Go live
▼
✓
Import your GitHub repo on Vercel
Go to vercel.com/new → Import Git Repository → select your cramforge repo. Framework should auto-detect as Vite. Click Deploy.
✓
Add all environment variables
Vercel dashboard → your project → Settings → Environment Variables. Add every variable from your .env file (same names and values). Then click Redeploy.
✓
Add Stripe webhook
Stripe dashboard → Developers → Webhooks → Add endpoint. URL: https://your-vercel-url.vercel.app/api/webhook. Events: checkout.session.completed and customer.subscription.deleted. Copy the signing secret → add as STRIPE_WEBHOOK_SECRET in Vercel env vars → Redeploy.
